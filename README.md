# Coupled Cart-Pendulum System with Torsional Springs

Project work for the course *Applied Mechanics 1* (Politecnico di Bari, MSc).

The system consists of a cart-pendulum assembly coupled through torsional springs. The repository contains the MATLAB derivation of the equations of motion and a Simulink/Simscape model used to simulate the system's dynamics.

![Frames and Coordinates](Frames%20and%20Coordinates.png)

## Repository contents

| File | Description |
|---|---|
| `Motion_Equations.mlx` | Derivation of the full (dimensional) equations of motion of the system. |
| `NonDimensional_Motion_Equations.mlx` | Non-dimensionalization of the equations of motion. |
| `Linearized_System.mlx` | Linearization of the equations of motion about the equilibrium position. |
| `Simscape_Model.slx` | Simulink/Simscape model used to simulate the system. |
| `Frames and Coordinates.png` | Reference frames and generalized coordinates used throughout the derivation. |

## Requirements

- MATLAB with Simulink and Simscape (Multibody) installed.

## How to run

The Simulink model (`Simscape_Model.slx`) does **not** define its own parameters and initial conditions: it reads them from the MATLAB workspace. Therefore, before opening/running the Simulink model:

1. Open MATLAB.
2. Run **at least one** of the `.mlx` live scripts (e.g. `Motion_Equations.mlx`) so that the system parameters and initial conditions are loaded into the MATLAB workspace.
3. Open `Simscape_Model.slx` and run the simulation.

> Note: MATLAB/Simulink cache files (`*.slxc`, `slprj/`) are not tracked in this repository, as they are automatically regenerated by MATLAB/Simulink on each machine.
